# Image Assets Guide

All images on the cloned website are organized in this folder (`public/assets/images/`). You can simply replace any of these files with your own images using the same filenames:

| Filename | Section / Usage | Description |
| :--- | :--- | :--- |
| `hero-frame.webp` | Hero Section | Background ambient visual of Cape Town |
| `persona-buyer.webp` | Personas | Buyers card visual |
| `persona-seller.webp` | Personas | Sellers card visual |
| `persona-tenant.webp` | Personas | Tenants card visual |
| `persona-landlord.webp` | Personas | Landlords card visual |
| `deal-church-street.webp` | Done Deals | CBD 24,000 m² Bulk - Church St Development Site |
| `deal-armchair.webp` | Done Deals | Observatory 573 m² - Lower Main Rd Restaurant & Bar |
| `deal-the-silo.webp` | Done Deals | V&A Waterfront 1,120 m² - The Silo Office |
| `deal-buitengracht.webp` | Done Deals | CBD 4,864 m² - Buitengracht St Mixed Use |
| `deal-loop-street.webp` | Done Deals | CBD - Loop Street Retail |
| `deal-burg-street.webp` | Done Deals | CBD 1,078 m² - Burg Street Residential |
| `deal-wembley-square.webp` | Done Deals | Gardens - Wembley Square Retail |
| `full-banner.webp` | Statement Banner | "We don't list our properties on purpose" banner |

Supported formats: `.webp`, `.jpg`, `.jpeg`, `.png`.
